# Model Routing

Sol plans/integrates and independently reviews frozen heads; Luna inventories and
applies judgment; Terra owns tracked implementation. Luna judgment routes to
Terra. Ordinary internal subagents are never Luna/Sol evidence and independent
Sol has no implementation history.

Default review thinking is medium. High risk includes security/privacy, public
contracts, persistence, concurrency, migration, and architecture-policy changes.
After three same-cause failures, escalate to Sol for redesign; Critical findings
or a specification contradiction require high-thinking Sol review.

Use types/Cargo/schema/Clippy/codegen before syntax-local AST. Do not emulate
compiler semantics with cross-file resolution, alias fixed points, macro
expansion, or type inference.
