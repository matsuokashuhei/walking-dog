# Walking Dog プライバシーポリシー

初版日: 2026年6月7日

Walking Dog 運営者（以下「運営者」といいます。）は、犬の散歩記録アプリ「Walking Dog」（以下「本サービス」といいます。）におけるユーザーの個人情報および関連する情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。本ポリシーは法務レビュー前のドラフトであり、公開前に専門家による確認を行うことを前提としています。

## 2. 取得する情報

運営者は、本サービスの提供に必要な範囲で、次の情報を取得します。

1. アカウント情報
   - メールアドレス
   - パスワードその他認証に必要な情報
   - 認証確認コード、認証トークン、リフレッシュトークン
   - アカウント作成日時、更新日時、ユーザー ID
2. ユーザープロフィール情報
   - ユーザー名
   - ユーザープロフィール画像
3. 犬プロフィール情報
   - 犬の名前、犬種、性別、誕生日
   - 犬のプロフィール画像
   - 犬ごとの散歩目標
4. 散歩記録
   - 散歩の開始日時、終了日時、散歩時間
   - 散歩距離、散歩回数、履歴、集計値
   - 散歩対象の犬
   - 散歩中に記録された位置情報、経路、記録時刻
5. 散歩イベント
   - 排泄、匂い嗅ぎ、あいさつ等のイベント種別
   - イベントの発生日時
   - イベント地点の位置情報
   - イベント対象の犬
6. 端末およびアプリ利用に関する情報
   - アプリの表示言語、単位、外観設定
   - アプリのバージョン
   - 通信時に一般的に送信される IP アドレス、リクエスト日時、レスポンス情報
   - エラー、不正利用、セキュリティ対応に必要なログ
7. 端末内または連携機能で扱う情報
   - SecureStore に保存される認証トークンおよびリフレッシュトークン
   - AsyncStorage に保存される表示設定、未送信の散歩イベント、アクティブな散歩状態
   - iOS の Live Activity、ウィジェット、Apple Watch 連携に必要な散歩状態、犬の名前、イベント回数、距離、最新位置情報
8. 問い合わせ情報
   - 問い合わせ内容
   - 返信先情報
   - 本人確認や調査に必要な情報

## 3. 写真、カメラ、位置情報の取扱い

1. 本サービスは、ユーザーおよび犬のプロフィール画像を登録するため、ユーザーが選択した写真を取得し、サーバーへアップロードすることがあります。
2. 本サービスは、散歩経路、距離、散歩イベント地点を記録するため、端末の位置情報を取得し、サーバーへ送信することがあります。
3. 位置情報は、ユーザーが端末の位置情報権限を許可した場合に利用します。バックグラウンドでの位置情報記録は、ユーザーが必要な権限を許可した場合に限り利用されます。
4. 本サービスは、現行アプリにおいて、散歩中の写真イベント機能に関連する端末内処理等のため、カメラ権限を要求することがあります。ただし、散歩中の写真アップロード機能は、現時点では提供中の機能として扱いません。
5. ユーザーが端末の写真ライブラリやカメラで選択または撮影した画像であっても、ユーザーが本サービス上で登録または送信しない限り、運営者は当該画像をサーバーに保存しません。

## 4. 利用目的

運営者は、取得した情報を次の目的で利用します。

1. 本サービスのアカウント登録、本人確認、認証、サインイン、サインアウト、認証状態の維持のため
2. ユーザープロフィールおよび犬プロフィールを作成、表示、編集、管理するため
3. 犬ごとの散歩目標を設定、編集、表示するため
4. 散歩の開始、経路記録、終了、履歴表示、距離・時間・回数等の集計を行うため
5. 散歩イベントを記録、表示、集計するため
6. iOS の Live Activity、ウィジェット、Apple Watch 等に散歩状態を表示し、操作を同期するため
7. プロフィール画像を保存、配信、表示するため
8. ユーザーからの問い合わせ、依頼、苦情、相談に対応するため
9. 本サービスの不具合調査、品質改善、機能改善、利用状況分析を行うため
10. 不正利用、なりすまし、セキュリティ事故、権利侵害、利用規約違反への対応のため
11. 重要なお知らせ、規約・ポリシー変更、メンテナンス、障害、セキュリティに関する連絡のため
12. 法令、裁判所、行政機関その他公的機関からの要請に対応するため

## 5. 端末内に保存される情報

1. 本サービスは、認証トークンおよびリフレッシュトークンを SecureStore に保存します。Web で利用する場合は、ブラウザの localStorage を利用することがあります。
2. 本サービスは、表示言語、距離単位、外観設定を AsyncStorage に保存します。
3. 本サービスは、通信できない状態で記録された一部の散歩イベント、アクティブな散歩状態、送信済み位置情報数等を AsyncStorage に保存することがあります。
4. 本サービスは、Live Activity、ウィジェット、Apple Watch 連携のため、散歩状態の一部を端末内または Apple のアプリグループ領域に保存することがあります。
5. 端末内に保存される情報は、本サービスの動作、復元、表示、同期のために利用されます。端末の設定、OS、アプリ削除、ストレージ状態により、これらの情報は削除または利用不能になることがあります。

## 6. 第三者提供

1. 運営者は、法令に基づく場合を除き、あらかじめユーザー本人の同意を得ることなく、個人データを第三者に提供しません。
2. 次の場合は、法令上第三者提供に該当しない場合があります。
   - 利用目的の達成に必要な範囲で、個人データの取扱いを外部事業者に委託する場合
   - 合併、事業譲渡その他の事業承継に伴って個人データが提供される場合
   - 法令に基づき提供が認められる場合
3. 運営者は、第三者提供に該当する取扱いを行う場合、法令に従い、必要な同意取得、通知、公表、記録その他の手続を行います。

## 7. 委託先および外部サービス

運営者は、本サービスの提供、保守、認証、保存、配信、インフラ運用のため、次の外部サービスまたは機能を利用することがあります。

1. AWS
   - Cognito: メールアドレス、認証情報、認証トークン、確認コード等のアカウント認証に利用します。
   - S3: ユーザーおよび犬のプロフィール画像等のファイル保存に利用します。
   - DynamoDB: 散歩中の位置情報記録に利用します。
   - CloudFront: プロフィール画像等の配信に利用します。CloudFront は特定リージョンではなく全世界のエッジロケーションを用いる CDN であるため、配信対象の画像等が日本国外を含むエッジロケーションで処理、キャッシュ、配信されることがあります。
   - その他 AWS の関連機能: API、データベース、キュー、ログ、インフラ運用に利用します。
2. Apple および OS 機能
   - 位置情報権限、写真ライブラリ権限、カメラ権限、Live Activity、ウィジェット、Apple Watch 連携、SecureStore 相当の安全な保存領域、アプリグループ領域等の機能を利用します。
3. Expo / React Native 関連機能
   - アプリの実行、位置情報、画像選択、ファイル読取、端末内保存、ウィジェット連携等のため、Expo および React Native のライブラリを利用します。

運営者は、委託先に対して、委託した個人データの安全管理が図られるよう、必要かつ適切な監督を行います。

## 8. 外国にある第三者への提供

1. 本サービスで利用する外部サービスの提供事業者、サーバー、データ保存先、サポート拠点は、日本国外に所在する場合があります。
2. CloudFront は全世界のエッジロケーションを通じてプロフィール画像等を配信するため、配信対象データは、日本国外を含む地域で処理、キャッシュ、配信されることがあります。
3. 運営者が外国にある第三者へ個人データを提供する場合、法令に従い、必要な情報提供、同意取得、体制確認、記録その他必要な措置を講じます。
4. 外部サービスの提供地域、保存地域、事業者情報は、各外部サービスの公開情報、契約条件、管理画面等に基づき確認し、必要に応じて本ポリシーに反映します。

## 9. 広告、解析、トラッキング

1. 運営者は、現時点で、第三者広告配信、広告目的の行動追跡、広告目的のデータブローカーへの提供を行いません。
2. 運営者は、現時点で、広告配信やアクセス解析を目的とした外部ライブラリを本サービスに組み込んでいません。
3. 運営者が将来、広告、アクセス解析、計測、マーケティング目的の外部サービスを導入する場合、取得する情報、利用目的、第三者提供の有無、オプトアウト方法等を本ポリシーまたは別途の表示で明らかにします。

## 10. 保存期間

1. 運営者は、利用目的の達成に必要な範囲で、個人情報を保存します。
2. アカウント情報、ユーザープロフィール、犬プロフィール、散歩記録、位置情報、散歩イベントは、ユーザーが本サービスを利用している期間、または本サービスの提供、問い合わせ対応、不正利用防止、法令対応に必要な期間保存します。
3. ユーザーが犬プロフィールを削除した場合、当該犬プロフィールに関する情報は、サービス運営上必要な範囲を除き削除または利用停止します。
4. アカウント削除、データ削除、利用停止等に関する請求は、本ポリシーの問い合わせ先メールアドレスで受け付け、法令および本サービスの実装状況に従い対応します。
5. 端末内に保存された情報は、ユーザーがアプリを削除した場合、端末設定により削除した場合、または本サービスの処理により削除された場合に消去されることがあります。

## 11. 安全管理措置

運営者は、個人データの漏えい、滅失、毀損、不正アクセス、不正利用を防止するため、サービスの規模、性質、取扱情報、リスクに応じて、次の安全管理措置を講じます。

1. アカウント認証、認証トークン管理、アクセス制御
2. SecureStore 等による端末内認証情報の安全な保存
3. クラウドサービス上のアクセス権限管理
4. ファイル保存先、データベース、キュー、配信基盤の権限管理
5. 通信経路の保護
6. ログ確認、障害調査、不正利用調査
7. 委託先の選定、管理、監督
8. 漏えい等が発生した場合の調査、影響範囲の確認、再発防止、本人通知、個人情報保護委員会への報告等、法令に従った対応

## 12. ユーザーの権利

1. ユーザーは、法令に従い、自己に関する保有個人データの開示、訂正、追加、削除、利用停止、消去、第三者提供の停止、第三者提供記録の開示を請求できます。
2. 運営者は、本人確認を行ったうえで、法令に従い、合理的な期間内に対応します。
3. 開示、訂正、削除、利用停止等の請求は、本ポリシーの問い合わせ先メールアドレスでのみ受け付けます。現時点で、アプリ内の専用フォームは提供していません。
4. 請求を行うユーザーは、対象アカウントのメールアドレス、請求内容、本人確認に必要な情報を、問い合わせ先メールアドレス宛てに送付してください。代理人による請求の場合、運営者は、本人確認に加えて代理権の確認を行います。
5. 開示等の請求に関する手数料は、現時点では無料です。今後手数料を定める場合、運営者は、請求への対応前にその内容を案内します。
6. 請求内容によっては、本サービスの全部または一部を利用できなくなる場合があります。
7. 法令上、請求に応じる必要がない場合、または本人確認ができない場合、運営者は請求に応じないことがあります。その場合、法令に従い理由を説明します。

## 13. 未成年者の個人情報

未成年のユーザーは、親権者その他の法定代理人の同意を得たうえで本サービスを利用してください。法定代理人から未成年者の個人情報に関する問い合わせ、開示、訂正、削除、利用停止等の請求があった場合、運営者は、本人確認および代理権確認を行ったうえで、法令に従い対応します。

## 14. 匿名加工情報および統計情報

1. 運営者は、個人を識別できない形に加工した統計情報を、本サービスの改善、品質向上、分析、研究、広報等の目的で利用することがあります。
2. 運営者が法令上の匿名加工情報を作成または第三者に提供する場合、法令に従い、必要な公表、管理、記録その他の措置を講じます。

## 15. 本ポリシーの変更

1. 運営者は、法令改正、本サービスの内容変更、取扱情報の変更、外部サービスの変更、運用上の必要に応じて、本ポリシーを変更することがあります。
2. 運営者は、本ポリシーを変更する場合、変更内容、変更後のポリシー、効力発生日を、本サービス内での表示、Web サイトへの掲載、メールその他適切な方法により周知します。
3. 変更後の本ポリシーは、周知した効力発生日から適用されます。
