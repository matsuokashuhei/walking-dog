# Dog Management Errors

| Code | Meaning |
| --- | --- |
| `INVALID_DOG_NAME` | normalized name invalid |
| `INVALID_BREED` | breed exceeds content rule |
| `INVALID_BIRTHDAY` | future or older than 40 years |
| `INVALID_GOAL` | minutes/cycle invalid |
| `GOAL_PERIOD_CONFLICT` | date range overlaps |
| `DOG_NOT_FOUND` | missing、removed、unauthorized |
| `DOG_NOT_ACTIVE` | mutation/start attempt on removed Dog |
| `MEDIA_NOT_READY` | avatar invalid |
| `VERSION_CONFLICT` | concurrent update |
| `IDEMPOTENCY_CONFLICT` | request ID reused |
