# Media Errors

| Code | Meaning |
| --- | --- |
| `UNSUPPORTED_CONTENT_TYPE` | source type is not accepted |
| `FILE_TOO_LARGE` | purpose limit exceeded |
| `PIXEL_LIMIT_EXCEEDED` | decoded dimensions are unsafe |
| `CHECKSUM_MISMATCH` | uploaded bytes differ from declaration |
| `INVALID_IMAGE` | decoder or content sniffing rejected source |
| `UPLOAD_EXPIRED` | grant expired before completion |
| `ASSET_NOT_READY` | pending、processing、rejected、deleted |
| `ASSET_NOT_FOUND` | unknown ID without existence leak |
| `STORAGE_UNAVAILABLE` | object storage temporary failure |
| `STORAGE_INCONSISTENT` | ready metadata and object disagree |
| `IDEMPOTENCY_CONFLICT` | request ID reused with another payload |
