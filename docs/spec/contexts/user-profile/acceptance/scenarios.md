# User Profile Acceptance Scenarios

- `USR-A01`: MeにProfile、Identity email、History summaryを表示する。
- `USR-A02`: History失敗時もProfileを表示し、summaryを0へ偽装しない。
- `USR-A03`: display nameとready user avatarを保存し、戻ったMeへ反映する。
- `USR-A04`: 未変更Saveではmutation/eventを発生させない。
- `USR-A05`: concurrent updateを上書きせずVERSION_CONFLICTを表示する。
- `USR-A06`: Units変更がMe、dog history、walk detailのformatへ一貫して反映される。
- `USR-A07`: Language、Appearance、Notificationsを再起動後も復元する。
- `USR-A08`: Avatar upload失敗後も元のavatarと入力名を保持する。
- `USR-A09`: SettingsからIdentity-owned Change EmailとSign Outへ遷移する。
- `USR-A10`: Dynamic Type、VoiceOver、日本語・英語、Light・Darkで操作できる。
