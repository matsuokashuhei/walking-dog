# User Profile Routes

| Surface | Route | Owner |
| --- | --- | --- |
| Me tab | `/user` | User Profile composition |
| Edit Profile | `/user/edit` | User Profile |
| Settings | `/settings` | User Profile |
| Change Email | `/settings/email` | Identity & Access |

Me tabからChange Emailへ進むとIdentity-owned screenを開きます。route implementationをUser Profileへ複製しません。
