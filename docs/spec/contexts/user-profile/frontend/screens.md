# User Profile Screens

## Me

avatar、display name、Identity email、walking since、lifetime summary、weekly graph、Edit、Change Email、Settingsを表示します。summaryとgraphはHistory-owned dataです。

## Edit Profile

avatar picker、display name、Cancel、Saveを表示します。phone、location、bio、public sharingを表示しません。Save中はformとCancelを無効にし、二重submitを防ぎます。

## Settings

Language、Units、Notifications、Appearance、Terms、Privacy、About、Sign Outを表示します。Change passwordは表示しません。Sign OutはIdentity commandです。

Achievementsとself-service account deletionは初期scope外です。
