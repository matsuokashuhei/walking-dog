# User Profile Product Purpose

- `USR-001`: Userは自分の表示名とavatarを管理できます。
- `USR-002`: locale、units、appearance、notificationsを一貫して設定できます。
- `USR-003`: ProfileはIdentity emailとHistory metricsを所有せず、公開contractから表示します。

## Product Axes

- 犬の体験: 誰と歩いたかを人間に分かりやすくします。
- データによる散歩の最大化: localeとunitsを全表示の基準にします。
- 飼い主の貢献心: 自分のprofileと活動成果を一つのMe surfaceで見せます。
