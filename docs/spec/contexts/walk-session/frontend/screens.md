# Walk Session Screens

## Start

散歩可能な犬を一覧し、一頭以上の選択後に開始します。進行中Walkがある場合は新規開始ではなく復帰導線を表示します。

## Active

経過時間、Track契約から得る暫定距離と経路、参加犬、排尿・排便・写真操作、終了操作を表示します。GPS精度低下とオフライン状態を隠しません。

## Finish

確定距離、所要時間、参加犬、イベント数を表示し、任意のメモ・気分・天気・タグを入力します。「保存」と「スキップ」はどちらも明示操作です。

## Recovery

中断した段階、未送信件数、再試行可能性を示し、同じWalkへ復帰します。
