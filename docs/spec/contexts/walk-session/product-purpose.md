# Walk Session Product Purpose

Walk Sessionは、利用者が一頭以上の犬との散歩を迷わず開始し、途中のケアイベントを残し、欠損なく完了できるようにします。

## Success

- 開始操作後、選択した犬と開始時刻を持つactiveな散歩が一意に作られる。
- 通信断やアプリ終了が起きても、同じ散歩へ復帰できる。
- 排泄、写真、終了時の感想が時系列に残る。
- 完了時点でTrack Recordingの確定距離を参照し、履歴へ一度だけ公開する。

## Initial Scope

複数犬での散歩、排尿・排便イベント、写真参照、メモ、気分、天気、タグ、復旧を含みます。予定作成、ライブ共有、経路推薦、課金は含みません。
