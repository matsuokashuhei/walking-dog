# 犬詳細画面 E2Eテスト項目

犬詳細画面 `/dogs/{id}` の現行実装を基準に整理します。

## 1. 取得・初期表示

- 犬一覧または登録成功後に対象犬の詳細を開く
- 読み込み中はLoadingを表示する
- Hero画像、犬名、年齢・犬種または性別を表示する
- BackとEditを表示する
- 散歩統計、Goal progress、Walksをこの順序で表示する
- 直接URLで開いた場合も表示し、Back履歴がなければDogsタブへ戻る
- 他ユーザーの犬、不正ID、削除済み犬を表示しない

現状差分：犬取得エラー・Not FoundはLoadingと区別されず、永久ローディングに見える可能性があります。

## 2. Hero・基本情報

- 写真ありは登録画像、なしはfallbackを表示する
- 長い犬名を1行で安全に表示する
- 誕生日から年齢を計算する
- 犬種があれば年齢と犬種、犬種なしでは性別を表示する
- 誕生日不明、未来日、不完全年月日でも不正な年齢を表示しない
- 画像URL失敗時にfallbackへ切り替える

## 3. 散歩統計

- total walks、distance、durationをAPI値どおり表示する
- 0件を正しく表示する
- 新しい散歩後に集計を更新する
- 履歴取得失敗時は誤った0統計を表示しない
- null、負値、巨大値でレイアウトや計算を破損させない

## 4. Goal progress

- 日次目標は今日のminutes/goalを表示する
- 週次目標は今週のminutes/goalを表示する
- progressを0〜100%で表示する
- 目標超過時は100%でclampする
- 散歩完了後に進捗が増える
- 目標なしでは既定目標の仕様に従う
- 履歴取得失敗時に誤った進捗を表示しない

## 5. Walksセクション

- 対象犬が参加した最新散歩を最大5件表示する
- 他犬だけの散歩を表示しない
- 複数犬散歩を表示する
- 日付、距離、時間、ペース、Pee/Poop件数を表示する
- 0件では空状態を表示する
- 取得失敗ではエラーとRetryを表示し、成功後に復旧する
- 行を押して正しい散歩詳細へ遷移する

現状差分：独立一覧へのSee all導線は接続されていません。

## 6. Back・Edit・状態更新

- Backで犬一覧へ戻る
- Editで `/dogs/{id}/edit` へ遷移する
- 編集保存後に最新情報を表示する
- 編集キャンセル後は元の情報を維持する
- 犬削除後、古い詳細へ戻らない
- 連続タップでrouteを多重に積まない

## 7. アクセシビリティ・証跡

- 犬名をheaderとして読み、Back、Edit、統計、進捗、履歴を識別する
- Dynamic Type、VoiceOver、日本語・英語、Light・Darkで確認する
- Loading、通常、0件、履歴エラー、Retry、更新後を画像・動画で保存する
- API fixtureと統計・目標・履歴表示を比較する
